 Zoom:

Projeto web desenvolvido com HTML e CSS, com foco na construção de uma interface moderna, responsiva e organizada utilizando Grid Layout e Flexbox.

Tecnologias utilizadas:
- HTML
- CSS
- CSS Grid
- Flexbox

Funcionalidades:
- Layout responsivo
- Estruturação moderna de páginas
- Organização de elementos utilizando Grid e Flexbox
- Interface voltada para melhor experiência visual do usuário

 Projeto Online:
https://enzorodrigues349.github.io/zoom/

Objetivo do Projeto:
Este projeto foi desenvolvido com o objetivo de aprimorar conhecimentos em desenvolvimento front-end, praticando responsividade, alinhamento de elementos e criação de layouts modernos utilizando HTML e CSS.
